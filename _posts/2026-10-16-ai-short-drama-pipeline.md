我用 AI 完整做了两代短剧：先是零成本的图文动效流（《战神归来》，爽剧题材），后来升级到图生视频流（《凌晨3:33》，30 秒悬疑先导片）。两条管线都跑通了成片。这篇把完整生产线拆开讲——不是理论，是踩过坑之后的工作流。

## 先想清楚：两条路线怎么选

| | 图文动效流 | 图生视频流 |
|---|---|---|
| 画面 | AI 生成关键帧 + 缓推/横移动效 | 关键帧 → AI 生成 5-10s 运动 |
| 质感 | 网络动画感 | 接近真人短剧 |
| 成本 | **≈ ¥0**（免费生图 + ffmpeg） | ¥40-60 / 30s 起 |
| 制作周期 | 一晚上 | 一两天（含验收迭代） |
| 适合 | 验证剧本、起号、图文流账号 | 正经短剧质感、先导片 |

我的建议：**剧本先用零成本流验证，钩子成立再上视频流。** 大多数短剧死在剧本，不是死在画质。

## 第一步：剧本和分镜表（决定 80% 的成败）

短剧的生死线是前 3 秒。分镜表必须一镜一钩子。以《凌晨3:33》为例：

| # | 时长 | 画面 | 钩子 |
|---|------|------|------|
| S1 | 6s | 床头柜闹钟 3:33，手机突然亮起，来电"未知号码" | 深夜神秘来电 |
| S2 | 6s | 女主接电话，表情从迷糊到瞳孔骤缩 | 电话那头是她自己的哭声 |
| S3 | 6s | 走廊频闪，她缓步前行 | 哭声在说：别回头 |
| S4 | 6s | 她背对镜子，镜中倒影缓缓转头微笑 | 核心反转（无旁白，只剩呼吸声） |
| S5 | 6s | 瞳孔大特写 → 猛回头 → 黑屏白字 | "可她已经回头了。" |

注意 S4 的设计：**最高潮的镜头反而没有旁白**——留白比台词狠。

写分镜表时同时锁定三件事：**光源规划**（全片冷蓝月光基调，唯一暖光出现在镜面——用光的异常制造不安）、**运镜方式**（每镜写死：微距推近/低角度横移/固定过肩）、**零高危画面**（零群像、零复杂手部动作——AI 视频最容易翻车的两样）。

## 第二步：角色一致性——定妆照先行

这是 AI 短剧第一难题：怎么让每个镜头里的人是同一个人。

我的做法是**定妆照先行 + 参考图挂死**：

1. 先集中生成角色定妆照（正面 + 3/4 侧两张），反复抽卡直到满意，锁定
2. 之后所有生图、生视频全部挂这两张参考图
3. prompt 里角色描述写成**常量**（一段固定文字，逐字复用），场景部分才是变量：

```bash
MAN="30-year-old Chinese man, short black hair, sharp eyebrows,
cold piercing eyes, long black wool coat"   # 这个字符串全程不改
```

4. 生图固定 seed，进一步收窄随机性

**链式连续性**解决镜头衔接：S2 的尾帧作为 S3 的首帧参考，S3 尾帧接 S4 首帧——画面像接力棒一样传下去，不会跳戏。主流的图生视频工具（可灵、即梦、海螺、Vidu）都支持首尾帧控制，这是选工具的硬指标。

## 第三步：生成画面

**零成本流**：免费生图（如 FLUX 系免费接口）出 8 张 1280×720 关键帧，然后 ffmpeg 一行命令把静态图变成"伪视频"：

```bash
ffmpeg -loop 1 -i s1.jpg \
  -vf "zoompan=z='min(zoom+0.0008,1.15)':d=${frames}:s=1280x720:fps=25" \
  -t ${dur} seg1.mp4
```

zoompan 缓推是成本最低的"运动感"，配合卡点配音，图文账号完全够用。

**视频流**：定妆照 + 分镜 prompt 逐镜生成 6s 视频。运镜全部从简——推近、横移、固定三件套。运镜越花，AI 抽风概率越大。

## 第四步：声音设计（被低估的质感来源）

画面的廉价感能被声音救回来一半。四层：

1. **旁白**：TTS 选贴合的低沉男声，语速 -8%，别用默认语速（太快显得急）
2. **真实音效**：心跳、电流频闪、脚步、低频氛围——用素材库，不要 AI 合成噪声
3. **音乐 ducking**：旁白出现时背景音乐自动压低（`sidechaincompress` 或剪辑软件手动拉）
4. **静默**：高潮前抽掉所有声音，只留呼吸。S4 那一镜的无声处理比任何配乐都吓人

**音画对齐的工程化技巧**：让画面时长跟着配音走——`每段时长 = 配音实测时长 + 1.2s 缓冲`，用 ffprobe 批量读音频时长再算段长，不需要手工对轴。

## 第五步：分步验收制

两个项目都用同一条纪律：**每步验收通过再进下一步**。

```
剧本+分镜表 → 定妆照 → 关键帧QC → 单镜视频逐镜看 → 粗剪 → 声音 → 终剪 → 交付
```

- 每步只看一件事：关键帧阶段只管构图和角色像不像，别被"镜头动起来什么样"分心
- 任何一步两轮修改不过 → 降级方案（换镜头设计，或退回静态图+动效兜底）
- 这条纪律省的是真金白银：视频生成是按次收费的，废片率直接决定成本

## 成本实账

30 秒悬疑片（5 镜）：关键帧 5 张 + 6s 视频 5 段，**¥40-60**。对比传统拍摄（演员、场地、器材、团队），成本差两个数量级。这就是 AI 短剧在 2026 年可行的原因：**试错成本便宜到可以反复重来**。

## 总结

- 剧本先行，钩子密度决定生死，先零成本验证
- 角色一致性 = 定妆照 + 参考图 + 常量描述 + 链式首尾帧
- 运镜从简，避开群像和手部特写
- 声音四层设计，静默是武器
- 分步验收，废片率就是成本
